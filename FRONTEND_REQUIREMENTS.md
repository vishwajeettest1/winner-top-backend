### Application Name: Winner 🏆 Top 1

1. **Client Registration**

   * Clients should be able to register in the application using their **mobile number and email address**.
   * The application should have approximately **10–12 videos uploaded**.
   * The client must watch each video **completely**.
   * Only after the video has been watched in full should the **winner amount/reward amount** be credited to the client's wallet.
   * **Referral earnings should be given significant importance** in the application.

2. **Fixed Amount to Start Earning**

   * The client should be able to start earning by paying/investing a **fixed amount** through the application.
   * The current product flow uses a fixed starter amount of **$25.00**.

3. **Wallet Balance**

   * The client should be able to view their **current wallet balance**.
   * After completing a video, the credited amount should be **immediately reflected in the wallet balance**.

4. **Referral System**

   * Clients should be able to **refer their friends**.
   * Each client should be provided with a **secure referral link** that they can share with others.

5. **Referral Amount Status**

   * After making a referral, the client should be able to **track the status of their referral amount/earnings**.

6. **Daily Video Watching & Earnings**

   * The client should be allowed to watch **10 videos per day**.
   * After completing the required videos, the applicable amount should be **immediately credited to the client's wallet**.

7. **Withdrawal Period & Countdown**

   * The minimum withdrawal amount should be **$50.00**.
   * The client should have a **7-day withdrawal period** for submitting a withdrawal request.
   * A **countdown timer** should be displayed showing the remaining time.
   * The system should also display the **expected withdrawal date** to the client.

8. **Help Center**

   * The application should have a dedicated **Help Center** section.
   * Clients should be able to find answers to **frequently asked questions (FAQs)** related to registration, video watching, earnings, wallet balance, referrals, and withdrawals.
   * Clients should be able to **contact customer support** if they face any issue or need assistance.
   * The Help Center should provide clear information about the application's **earning, referral, wallet, and withdrawal processes**.

9. **About Us**

   * The page should explain the platform's **mission and vision**, including its purpose and long-term goals.
   * It should describe the **services and products** offered to users.
   * It should share the platform's **background and story**, including how it started and the motivation behind its creation.
   * It should introduce the **founder and key team members**, including their names, expertise, experience, and photos if they wish to share them.
   * It should highlight **achievements and statistics**, such as user numbers, success rates, milestones, or other notable achievements.
   * It should provide **contact and support information**, including email, helpline number, and social media links where available.

10. **Add Money via UPI or Bank Account**

   * Clients should be able to add money to their wallet through **UPI** or a **bank account/net banking** option.
   * The application should create a secure payment order through a payment gateway.
   * The wallet should be credited only after the payment gateway confirms the transaction through server-side verification.
   * The application should show clear payment status and transaction information to the client.
